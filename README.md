### Шо робить цей скріпт?

Шукає сайзи на рівнях і без них.

### Як він це робить?

Є цикл, який шерстить графік і шукає екстремум з "кімнатою зліва".
Якщо екстремум знайдений - отримує снапшот поточного DOM (стакану).
Якщо в DOM є об'єм який ЗНАЧНО вирізняється відносно сусідніх і
він знаходиться на знайденому раніше екстремумі - відправляється сповіщення.

### Які є параметри?
#### Зайди в search_for_levels.py

c_room = 30  # кімната зліва у знайденого екстремуму
d_room = 10  # вікно зверху і знизу стакану для пошуку максимуму

wiggle_room_perc = 0.005 # можлива відстань сайзу від рівня
atr_dis = 4.0  # мультиплікатор відстані до сайзу в ATR
abs_dis = 0.7  # мультиплікатор відстані до сайзу %

size_mpl = 2.0  # мультиплікатор максимального сайзу відносно інших сайзів
vol_mpl_chart = 3.0  # мультиплікатор відносності об'єму (Volume)
vol_mpl_depth = 8.0  # мультиплікатор відносності об'єму якщо перевіряємо тільки сайз

### Чого тут не вистачає?

Тут відсутній main.env
Його ти маєш створити сам.
Розмісти там:

CHAT_ID - Твій тг ID
BOT_TOKEN - Токен боту в який ти хочеш отримувати повідомлення
